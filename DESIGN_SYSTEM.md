# Design System

## Visual direction

Civic-tech command center:

- dark navy foundation
- cyan operational accent
- restrained glass surfaces
- strong typography hierarchy
- dense but readable data views
- responsive layouts
- clear status badges

## Components

- animated header/navigation
- footer
- stat cards
- tables
- workflow cards
- status badges
- error states
- loading states
- public reporting form
- GIS map surface

## Motion

Framer Motion is used for meaningful entrance/hover/navigation transitions.

Future iterations should respect `prefers-reduced-motion` and avoid animation that obscures operational information.
