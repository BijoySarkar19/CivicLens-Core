# Demo Workflow

1. Start Compose.
2. Sign in with the environment-seeded administrator.
3. Create/import assets.
4. Open the asset registry and dashboard.
5. Submit an incident.
6. Create a work order and inspection.
7. Review analytics and audit records.
8. Submit a public incident through `/api/v1/public/incidents`.

Future completion work must make the full 22-step specification workflow executable end-to-end; this baseline does not pretend unfinished UI modules are complete.
